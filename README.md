# 🏥 Healthcare Appointment & Patient Portal

A responsive and user-friendly **Healthcare Appointment & Patient Portal** developed using **HTML5, CSS3, and Bootstrap 5**.

The project provides a hospital-style interface where patients can view hospital services, register their details, book appointments, check appointment information, and view health-related information.

🔗 **Live Demo:**

## 📌 Project Overview

The Healthcare Appointment & Patient Portal is a responsive frontend web application designed to provide a structured digital interface for patients and healthcare services.

The portal contains:

- Hospital homepage
- Patient registration
- Appointment booking
- Appointment dashboard
- Health information
- Doctor information
- Medical services
- Diagnostic and laboratory services
- Pharmacy services
- Emergency services
- Patient support services
- Administrative services
- Technologies section
- Responsive navigation
- Responsive design for different screen sizes

The project was developed as part of a **Software Development / Web Development training project**.

---

## 🎯 Objectives

The main objectives of this project are:

- To create a responsive healthcare website.
- To design a professional hospital-style user interface.
- To provide a patient registration form.
- To display appointment details in a structured table.
- To display patient health information.
- To provide information about doctors and departments.
- To organize hospital services into different categories.
- To practice HTML5 semantic elements.
- To practice CSS3 styling and responsive design.
- To implement Bootstrap 5 components and responsive utilities.

# 🚀 How to Run the Project

## Option 1: Run Locally

Clone the repository:

git clone https://github.com/abhinayakuchi-source/healthcare-portal.git

Move into the project directory:

cd healthcare-portal

Open:

index.html

in any modern web browser.

---

# 💻 Option 2: Use VS Code

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open index.html.
4. Install the Live Server extension.
5. Click Go Live.
6. The website will open in your browser.
