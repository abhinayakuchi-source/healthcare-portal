# 🏥 Healthcare Appointment & Patient Portal

## 📖 Overview
The Healthcare Appointment & Patient Portal is a responsive web-based application designed to manage patient registrations, appointments, and health information. Built with HTML5, CSS3, and Bootstrap 5, it provides a clean and accessible interface for patients and healthcare providers.

## 🚀 Features
- Patient Registration Form with validation
- Appointment booking and management
- Health Information display section
- Bootstrap cards for structured UI
- Navigation bar with multiple sections:
  - Home
  - Patient Registration
  - Appointments
  - Health Information
  - Services
  - Technologies

## 🛠 Tech Stack
- HTML5
- CSS3
- Bootstrap 5
